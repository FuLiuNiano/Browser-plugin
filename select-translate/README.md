# 划词翻译 (Select Translate) v1.2.2

本地加载的浏览器扩展(MV3)。三种模式:划词翻译 / 一键全文翻译(替换原文) / 对照翻译(保留原文)。Google 翻译为主引擎(双端点),失败自动切 MyMemory 兜底(国内直连可用)。

## 安装(Edge)

1. 打开 `edge://extensions`(如已装 v1,点扩展卡片上的「重新加载」即可升级)
2. 左下角开启「开发人员模式」
3. 点「加载解压缩的扩展」,选择解压出来的 `select-translate` 目录
4. 建议点工具栏拼图图标,把「划词翻译」固定到工具栏

Chrome 同理:`chrome://extensions` → 开发者模式 → 加载已解压的扩展程序。

## 三种模式(点工具栏图标,顶部三张卡片切换)

| 模式 | 行为 |
|---|---|
| 🔍 划词 | 选中文字出「译」按钮,点击出译文面板(默认) |
| 🌐 全文 | 译文**替换**原文,不保留 |
| 📑 对照 | **原文不动**,译文块插在旁边,带左侧竖线标识 |

- 全文/对照默认**打开页面即自动翻译**(设置里可关);无限滚动/翻页/SPA 换字由 MutationObserver 自动跟进(含文本节点替换与 open shadow DOM 穿透)
- **已翻译状态下切换「全文 ↔ 对照」会自动按新模式重排整页**(静默还原后立刻重翻;若原节点已因 SPA 重渲染失效,则刷新后按新模式继续自动翻),无需手动还原
- 角标实时显示进度(`…` → `65%` → `✓`);面板内 toast 提示结果
- 再按 `Alt+P` 或右键菜单「全文翻译 / 还原本页」即可还原
- 翻完后弹窗里按钮变为「**补翻遗漏**」:一键重扫页面补齐晚渲染/漏网内容(已翻的自动跳过)

## 不翻译的内容(避免账号/密码被翻、保排版)

- **表单一律不碰**:`input` / `textarea` / `select` / `option` 的值与占位符——密码、账号、验证码永远不会被读取或改写
- `contenteditable` 编辑区、`role=textbox`
- 代码:`code` / `pre` / `kbd` / `samp` / `var`;图标字体类(`.material-icons` / `.fa` / `.iconfont` 等)及 aria-hidden 中的"标识符样"文本(如 `arrow_forward` 连字)
- 约定免译:`translate="no"`、`.notranslate`、`script/style/template/svg`
- 智能跳过:纯链接、纯邮箱、无字母文本;目标中文时「无假名且几乎全是汉字」的段落(已是中文);目标英语时纯 ASCII 文本
- 注意:日文(含假名)、韩文(含谚文)会被正常翻译,不会被误判为"已中文"(v1.1.0 曾误判,v1.1.1 修复)

## 排版如何保持

- **对照模式**:原文 DOM 完全不动,只在旁边插入译文块;字体、字号、行高、对齐全部继承原文容器,仅加一条左侧蓝线标识,视觉上与原版几乎一致
- **全文替换**:只改文本节点内容,不动任何元素结构——链接仍是链接、加粗仍是加粗、按钮仍是按钮;译文按字符比例分配回原节点,空白节点保持原样,行高列宽随文字自然回流

## 划词面板

复制 / 朗读 / 📌固定(滚动、点击外部不关闭) / 拖动标题栏 / `Esc` 关闭;`Alt+T` 快捷键;右键菜单「翻译选中文字」

## 弹窗菜单其余内容

- 手动翻译输入框(折叠)
- 设置(折叠):启用开关、**自动翻译开关**、划词触发方式(点按钮/选中即译)、引擎、目标语言(13 种)、站点排除列表

## 网络与引擎链(三个端点均经 curl 实测)

- 端点1 `translate.googleapis.com/translate_a/single`(Google,POST):信息最全;出口 IP 被风控时返回 Sorry 页
- 端点2 `clients5.google.com/translate_a/t?client=dict-chrome-ex`(Chrome 内置翻译同款):风控宽松,同 IP 被风控时仍可用
- 端点3 `api.mymemory.translated.net`(MyMemory,免密钥):国内直连可用,匿名每日约 5000 字符额度
- 批量机制:多个文本块按行合并成一次请求,译后按行/按分句映射回各块(9 个映射用例单测通过);引擎选「自动」时 1→2→3 依次兜底
- 浏览器内能否访问 Google 取决于浏览器自身网络;全程无代理时 MyMemory 保证可用

## 文件

- `manifest.json` 清单(MV3);`background.js` 后台:单条/批量翻译、引擎链、角标、快捷键/右键转发
- `content.js` 页面脚本:划词 UI(Shadow DOM)+ 页面翻译(单元收集/替换/对照/观察器)
- `popup.html/css/js` 弹窗菜单;`icons/` 图标
- `tools/make_icons.py` 重新生成图标(Pillow);`tools/test-mapping.js` 映射逻辑自测(node 运行)
